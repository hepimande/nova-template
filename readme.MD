# Nova

A clean and minimal portfolio website template built with plain HTML, CSS, and JavaScript.

Nova is designed to be simple, easy to understand, and easy to customize — even if you're just getting started with HTML and CSS.

## Features

- Clean and minimal design
- Responsive layout
- Plain HTML, CSS, and JavaScript
- No frameworks or dependencies
- Reusable UI components
- Mobile-friendly navigation
- Modal component
- Accordion component
- Easy to customize
- Free for personal and commercial projects

## Getting Started

No build tools or installation required.

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

For a better development experience, you can use a local development server such as Live Server in Visual Studio Code.

## Customization

Nova is intentionally kept simple, so you can customize it without needing a framework or build tool.

### 1. Edit the Content

Open:

    index.html

You can change:

- Site name
- Navigation labels
- Headings and paragraphs
- Project information
- Services
- Button labels and links
- Footer content

### 2. Customize the Design

Open:

    css/style.css

You can adjust:

- Colors
- Typography
- Spacing
- Container width
- Borders
- Buttons
- Cards
- Section layouts

### 3. Customize Responsive Styles

Open:

    css/responsive.css

This file contains styles for smaller screen sizes.

You can adjust the layout and spacing for:

- Tablets
- Mobile devices

### 4. Customize Interactions

Open:

    js/main.js

This file handles the interactive parts of the template, such as:

- Mobile menu
- Modal
- Accordion

The JavaScript is kept lightweight and organized so it is easy to understand and modify.

### Tip

If you're new to HTML and CSS, start by editing the text in `index.html`.

Once you're comfortable with the structure, try changing the styles in `style.css`.

You don't need to understand everything before you start customizing. Change one thing at a time and use your browser to see the result.
